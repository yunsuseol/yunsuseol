Python과 통계 기초를 배우고 있으며, 실습하면서 이해한 내용과 막혔던 부분을 이곳에 기록합니다.

## 📚 지금 배우는 것

| 분야 | 연습하는 내용 |
| --- | --- |
| Python | 조건문, 반복문, 함수로 간단한 코드 작성하기 |
| pandas · NumPy | CSV 파일 읽기, 필요한 데이터 고르기, 결측값 확인하기 |
| SQL | `SELECT`로 조회하고 `GROUP BY`로 집계하기 |
| 통계 | 평균과 중앙값을 구하고 어떤 차이가 있는지 살펴보기 |
| Tableau | 차트를 만들고 데이터를 여러 기준으로 비교해 보기 |
